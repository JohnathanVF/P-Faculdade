# Projeto: Página de Receita em HTML e CSS

Este projeto foi desenvolvido de forma autônoma como parte dos estudos iniciais de desenvolvimento web, aplicando os conceitos fundamentais ensinados em sala de aula no início do semestre.

## 🛠️ Tecnologias Utilizadas

O projeto faz uso estrito de tecnologias nativas e essenciais da web:
* **HTML5:** Estruturação semântica da página, organização de conteúdos por meio de tabelas, listas e seções.
* **CSS Básico:** Estilização inicial de elementos e organização visual da interface.

## 📂 Estrutura do Código

O arquivo principal (`index.html`) foi construído para demonstrar o domínio de tags fundamentais do HTML:
* **Tabelas (`<table>`)**: Utilizadas para estruturar o layout e organizar o conteúdo principal da receita lado a lado.
* **Listas (`<ul>` e `<li>`)**: Empregadas na listagem organizada dos ingredientes e dos passos do modo de preparo.
* **Multimédia (`<img>`)**: Integração de elementos visuais ilustrativos para enriquecer a interface do usuário.

## 🚀 Como Executar

Por se tratar de um site estático desenvolvido apenas com HTML e CSS, nenhum servidor ou instalação complexa é necessária:

1. Faça o download ou clone este repositório.
2. Certifique-se de que a estrutura de pastas está mantida (com a imagem na pasta correspondente).
3. Abra o arquivo `index.html` diretamente em qualquer navegador web de sua preferência.
